# Better-Spotify-Data-Viewer

[IN DEVELOPMENT, SHIT BARELY WORKS]

There are a fuck ton of apps that claim to let you see your Spotify listening stats, but if you want to see anything actually relevant, you need to pay, which many simply don't wanna do. This is what this app does. You feed the app your data you downloaded from Spotify, and this thing formats it.

If you wanna build the app yourself, you gotta make a file called 'apikeys.py' and define in it your client_id and client_secret that you get from the Spotify dev bullshit thingy.
You also need to request your extended listening data from Spotify
